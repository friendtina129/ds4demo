# 2330 台積電近一個月股票資料分析專案

## 📌 專案介紹

本專案以 **台積電（股票代號：2330）** 為研究對象，透過網路爬蟲取得台積電**近一個月的股票交易資料**，擷取每日的**開盤價與收盤價**，經過資料清理與格式轉換後匯入資料庫，進一步利用 SQL 進行資料查詢與分析。

本專案主要實作「**網路爬蟲 → 資料清理 → 資料庫匯入 → 資料查詢 → 股票價格分析**」的完整流程，藉此學習 Python 網路爬蟲、資料處理及資料庫應用。

## 🎯 專案目的

本專案主要目的如下：

1. 使用網路爬蟲自動取得 **2330 台積電近一個月的股票資料**。
2. 擷取每日股票的**交易日期、開盤價與收盤價**。
3. 將爬取的原始資料進行清理與格式轉換。
4. 將處理完成的資料匯入資料庫保存。
5. 使用 SQL 查詢近一個月的股票價格資料。
6. 比較每日開盤價與收盤價的變化。
7. 建立簡單的股票價格分析與視覺化。

## 🕷️ 資料抓取

本專案使用網路爬蟲取得 **2330 台積電近一個月的每日股票資料**。

主要抓取以下資訊：

| 欄位         | 說明         |
| ---------- | ---------- |
| `date`     | 股票交易日期     |
| `stock_id` | 股票代號（2330） |
| `open`     | 當日開盤價      |
| `close`    | 當日收盤價      |

爬蟲程式會依照設定的日期範圍取得近一個月資料，並將每日交易資料整理成統一格式，方便後續進行資料庫匯入。

## 🗄️ 資料庫設計

將爬取並清理後的資料儲存至資料庫，例如建立 `stock_price` 資料表：

| 欄位名稱       | 資料型態    | 說明   |
| ---------- | ------- | ---- |
| `id`       | INT     | 資料編號 |
| `stock_id` | VARCHAR | 股票代號 |
| `date`     | DATE    | 交易日期 |
| `open`     | DECIMAL | 開盤價  |
| `close`    | DECIMAL | 收盤價  |

資料庫中的資料範例：

```text
stock_id | date       | open   | close
---------|------------|--------|--------
2330     | 2026-08-20 | 1180.0 | 1195.0
2330     | 2026-08-19 | 1165.0 | 1175.0
2330     | 2026-08-18 | 1150.0 | 1160.0
...
```

將近一個月的開盤價與收盤價匯入資料庫後，可以透過 SQL 查詢及 Python 進行分析，例如：

* 查詢每日收盤價
* 比較開盤價與收盤價差異
