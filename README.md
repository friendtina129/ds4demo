2330 台積電股票資料分析專案
📌 專案介紹
本專案以 台積電（股票代號：2330） 為主要研究對象，建立一套從網路資料蒐集、資料清理、資料庫儲存到資料分析的完整資料處理流程。

專案透過網路爬蟲（Web Scraping）自動取得台積電相關的股票歷史資料，將原始資料進行整理與格式化後，匯入資料庫保存，讓使用者能夠透過資料庫進行後續的股票價格查詢、趨勢分析及資料視覺化。

本專案的主要目的，是實作一個完整的 ETL（Extract、Transform、Load）資料流程，並透過實際的金融市場資料，學習網路爬蟲、資料處理、資料庫操作與資料分析等技術。

🎯 專案目的
本專案主要有以下幾項目的：

自動化資料蒐集

使用網路爬蟲取得 2330 台積電股票相關資訊。
減少人工下載與整理資料的時間。
建立可重複執行的資料蒐集流程。
資料清理與轉換

處理爬蟲取得的原始資料。
清除無效資料、缺失值及重複資料。
將日期、股價、成交量等欄位轉換為適合資料庫儲存的格式。
建立股票資料庫

將整理後的資料匯入資料庫。
建立結構化的股票歷史資料。
方便後續進行 SQL 查詢及資料分析。
股票資料分析

分析台積電歷史股價變化。
觀察開盤價、最高價、最低價、收盤價及成交量等資訊。
作為後續股票趨勢分析與資料視覺化的基礎。
學習完整資料工程流程

實作從「資料來源 → 爬蟲 → 資料清理 → 資料庫 → 分析」的完整流程。
熟悉 Python、Web Scraping、SQL 與資料庫整合應用。

🛠️ 使用技術
程式語言
Python

作為主要開發語言。
負責網路爬蟲、資料處理及資料庫操作。

🗄️ 資料庫設計
股票資料可依照以下欄位進行儲存：

欄位	說明
date	股票交易日期
stock_id	股票代號，例如 2330
open	開盤價
high	最高價
low	最低價
close	收盤價
volume	成交量
透過資料庫儲存後，可以使用 SQL 快速查詢特定日期、價格區間或成交量等資料，並提供後續資料分析使用。

🚀 專案特色
本專案不只是單純取得股票資料，而是建立一個完整的資料處理流程：

「網路爬蟲 → 資料清理 → 資料轉換 → 資料庫匯入 → SQL 查詢 → 資料分析」

藉由 2330 台積電作為實際案例，將網路資料蒐集與資料庫技術結合，建立可持續更新的股票資料平台，並作為後續資料分析、機器學習或金融科技應用的基礎。

⚠️ 本專案主要用於程式設計、資料工程與資料分析學習，不構成任何投資建議。
