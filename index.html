HTML 是網頁的
骨架與語言。

HTML 全名是 HyperText Markup Language。它不是用來「畫」頁面的工具，而是用標籤告訴瀏覽器：這段文字是標題、那個區塊是一張圖片。

!

先記住一件事
HTML 負責內容與意義，CSS 負責外觀，JavaScript 負責互動。

index.html
<!DOCTYPE html>
<html lang="zh-Hant">
  <body>
    <h1>Hello, web!</h1>
    <p>我的第一個網頁。</p>
  </body>
</html>

02 / CORE CONCEPTSBUILDING BLOCKS
A

標籤 Tag

用尖括號包住的關鍵字，描述內容的角色。大多數標籤都有開始與結束。

<h1>標題</h1>
B

元素 Element

一組完整的開始標籤、內容與結束標籤，就是一個 HTML 元素。

<p>內容</p>
C

屬性 Attribute

放在開始標籤裡的補充資訊，讓元素擁有更多設定或功能。

<a href="...">
